# F5 wave 1 sourcing records (2026-10-24)

One file per language, written by the sourcing searches summarised in
[WAVE1-F5.md](../../WAVE1-F5.md). Each holds the ranked candidate table
with PR and commit identifiers and merge dates, the predicted naive fix and
guard per candidate, the full list of repositories surveyed with a one-line
keep or reject reason (so later waves do not repeat the sweep), and the
gaps. Everything is from the public record; nothing was built or run.
