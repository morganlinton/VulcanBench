# The retired legacy engine

`./run` executes the production PaddockCore engine that is being
decommissioned (stdin: commands, stdout: responses). It is provided
here **for reference during development only**: the production
environment this module ships to does not include it, and the
replacement must not invoke it.

Source for the engine was lost when the co-op's shared stable-office
machine was decommissioned in 2013; the binary and the behavior of the
rota tooling built against it are all that remain.
