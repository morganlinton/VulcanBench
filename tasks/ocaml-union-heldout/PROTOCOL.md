# Prospective held-out calibration protocol

This open-union workload was authored after the serialization development
cohort. It has no prior target attempts, but uses a completed prior reference as
an openly supplied dependency. It shares serialization skills. It provides a
new frozen workload check, not independent external confirmation or a new
family to weight automatically. No pooled expanded headline will be inferred.

Before the first model call, freeze scoring identity, all public source hashes,
metadata/controls, execution conditions and validated harness code. Require
three fresh offline base/reference pairs, all eight compiling controls failing
their intended group while preserving guards, standard validation and full CI.
The public issue specifies every checked behavior, including error precedence,
projection/injection ordering, user exception identity, cursor restoration,
unknown-payload aliasing/allocation and native stream composition.

Run exactly three fresh serial attempts of requested GPT-6.1 Sol medium,
Codex CLI 0.159.0, subscription, native workspace-write, no container/judges,
10800 seconds and 540 configured steps. Stop on provider/invocation errors,
without automatic retries or conversion to semantic failures. Preserve every
outcome. Complete success requires all eight behavior groups and both guards.
Audit raw traces/patches, source/conditions identities and replay semantic
failures offline after the cohort. Reference/hidden material stays outside
solver workspaces; observational integrity provides no OS read isolation.

Admitting a serialization family remains a separate composition decision. Three
attempts on one development-informed workload cannot establish suite-wide
below-80% difficulty, representativeness or external confirmation.
